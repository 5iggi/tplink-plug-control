LoxBerry plugin for local control of TP-Link/Kasa smart plugs such as **HS100**, **HS110** and **KP115**.

## Features

- Switch relay on/off
- Switch LED on/off
- Read device status
- Set plug time to LoxBerry time
- LAN autodiscovery
- Loxone XML export for Virtual Output and Virtual Input HTTP
- Status endpoint for Loxone and external systems
- Log file for the LoxBerry log viewer

## Supported devices

- TP-Link HS100
- TP-Link HS110
- TP-Link KP115

Other TP-Link/Kasa smart plugs using the classic local TP-Link SmartHome protocol may work, but are not guaranteed.
