LoxBerry Plugin zur lokalen Steuerung von TP-Link/Kasa Smart Plugs wie **HS100**, **HS110** und **KP115**.

## Funktionen

- Ein-/Ausschalten des Relais
- LED ein-/ausschalten
- Gerätestatus auslesen
- Zeit des Plugs auf LoxBerry-Zeit setzen
- Autodiscovery im lokalen Netzwerk
- Loxone XML-Export für Virtual Output und Virtual Input HTTP
- Status-Endpunkt für Loxone und externe Systeme
- Logdatei für den LoxBerry-Logviewer

## Unterstützte Geräte

- TP-Link HS100
- TP-Link HS110
- TP-Link KP115

Weitere TP-Link/Kasa Smart Plugs mit klassischem lokalen TP-Link-SmartHome-Protokoll können funktionieren, sind aber nicht garantiert.
